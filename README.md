# The Phantom Atlas 🧭

An ongoing, daily-expanding digital archive documenting historical phantom islands, nonexistent mountain chains, speculative continents, and cartographical mirages that survived on official maps for decades — or centuries.

### Daily Schedule & Layout
- **Radar Scope Anomaly Selector**: Interactive coordinate sweep highlighting each target.
- **Case Files**: High-density historical breakdowns including coordinate records, exploration expeditions, and bathymetric sweeps.
- **Daily Expansion**: Each day, a newly unsealed phantom geographic entity is researched, plotted, and added to the atlas.
