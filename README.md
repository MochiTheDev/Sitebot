# The Phantom Frequency

A mobile-first static chronicle tracking strange radio transmissions, unclassified acoustic anomalies, and electromagnetic relics of the 20th and 21st centuries.

## Concept & Daily Expansion Plan
Each day, a new unverified, ghost, or historical mystery frequency is logged into the archive with coordinates, frequency specs, verified incident logs, and interactive browser-synthesized acoustic recreations (via Web Audio API).
